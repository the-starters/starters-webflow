# Edit Profile v3 test bundle

The baseline is the exact versions currently pinned on the test page: `v1.59.607` for the profile controllers and `v1.59.614` for the Work Experience rows and accordion. `manifest.json` records each source tag and byte hash. `python3 materialize.py` rebuilds the complete local `runtime/` from those immutable tags plus `patches/work-experience-month-picker.patch`; `python3 verify.py` checks the resulting files and loader references. The full runtime files are present locally but ignored by Git because copied legacy scripts contain service hostnames. The tracked manifest and patch preserve the bundle for later reconstruction without recommitting those hosts.
